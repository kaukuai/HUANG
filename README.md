# HUANG

FoodPro Studio 原型介面（純前端）

## 啟動方式
直接用瀏覽器打開 `index.html` 即可。

## 功能重點
- 用戶上傳食物照，並可上傳參考圖做風格模仿。
- 可調整景深、色調、布景、AI 發揮程度、細節等旋鈕。
- 內建 13 種常用拍攝角度（含簡易圖示）。
- 主體位置可選九宮格位置或中央。
- 光源方向可選（側光、逆光、頂光等）或不指定。
- 提供 Uber Eats / foodpanda 常見尺寸與封面格式。
- 提供單色調、青橘等色調對比預設。
- 菜單系列一致性鎖定：背景、光線、色調、角度可批次固定。
- 支援繁中、簡中、英文、日文、韓文。
